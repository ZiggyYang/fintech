## 📋 项目简介

这是一个金融科技方向的研究项目仓库，主要用于记录和分享金融科技相关的学习笔记、实验代码和研究成果。项目使用 Jupyter Notebook 进行交互式编程和数据分析。

**研究者**: 杨林芮 (Linrui Yang)  
**单位**: 上海财经大学 (Shanghai University of Finance and Economics)  
**方向**: 金融科技 (Financial Technology)

## 🎯 项目目标

- 掌握金融科技领域的核心技术和工具
- 探索金融数据分析与建模方法
- 记录学习过程和研究成果
- 构建可复用的金融分析代码库

## 🚀 快速开始

### 环境要求

- Python 3.9+
- Jupyter Notebook 或 JupyterLab
- Git

### 安装步骤

1. **克隆仓库**
   ```bash
   git clone https://github.com/ZiggyYang/fintech.git
   cd fintech
   ```

2. **创建虚拟环境（推荐）**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   # 或
   venv\Scripts\activate  # Windows
   ```

3. **安装依赖包**
   ```bash
   pip install jupyter numpy pandas matplotlib
   ```

4. **启动 Jupyter Notebook**
   ```bash
   jupyter notebook
   ```
